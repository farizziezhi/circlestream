# V1 Roadmap

## CircleStream v1.0 — Public Release

---

## 1. V1 Goals

- App siap untuk public launch
- Polish UX dari feedback MVP/beta
- Fitur-fitur yang paling diminta user
- Stabilitas dan performa yang baik
- Onboarding yang smooth

---

## 2. V1 Feature Set

### 2.1 Push Notifications

**Backend:**
- Integrasi dengan Firebase Cloud Messaging (FCM)
- Kirim notif saat: new post di circle, reaction ke post kita, member join/leave
- Endpoint untuk save FCM token: `POST /devices/register`
- User preference untuk notif: `PATCH /me/notification-settings`

**Flutter:**
- `firebase_messaging` plugin
- Background message handler
- Deep link ke screen yang relevan dari notif

**Notif Types:**
```
📸 {username} posted in {circle_name}
❤️ {username} reacted to your photo
👋 {username} joined {circle_name}
```

---

### 2.2 Delete Post

**Backend:**
- `DELETE /posts/:post_id` — hanya post owner
- Hapus metadata dari Turso
- Hapus file dari R2 (background job)
- Hapus Redis reaction counters
- Publish `post_deleted` event ke Ably

**Flutter:**
- Long press photo card → menu "Hapus"
- Confirmation dialog
- Post hilang dari feed semua device real-time

---

### 2.3 Circle Management (Owner Features)

- Rename circle: `PATCH /circles/:id`
- Transfer ownership: `POST /circles/:id/transfer-ownership`
- Remove member: `DELETE /circles/:id/members/:user_id`
- Delete circle: `DELETE /circles/:id`

---

### 2.4 Profile Enhancement

- Avatar upload (foto profil)
- Edit username
- Lihat semua post yang pernah diupload user
- Account deletion: `DELETE /me`

---

### 2.5 Multiple Circles in Feed

Saat ini feed hanya satu circle. V1:
- Bottom sheet circle selector di Feed
- Tab atau swipe antar circle
- Badge unread count per circle

---

### 2.6 Photo Viewer Improvement

- Pinch to zoom
- Swipe ke foto berikutnya/sebelumnya
- Download foto ke gallery (dengan watermark optional)
- Share foto ke luar app (native share)

---

### 2.7 Dark Mode

Design system perlu dark color palette:
```dart
class AppColorsDark {

  static const Color surface    = Color(0xFF252840);
  static const Color primary    = Color(0xFF7292CF);
```

---

### 2.8 Onboarding Flow

First-time user experience:
1. Welcome screens (3 slide)
2. Register/Login
3. Prompt: "Buat circle atau minta invite code dari teman"
4. If buat circle → langsung di invite screen dengan share button
5. Empty state yang friendly dengan CTA jelas

---

## 3. V1 Technical Improvements

### Backend
- Proper structured logging (JSON logs dengan levels)
- Pagination metadata yang lebih lengkap
- Background job queue (cleanup R2 files)
- API versioning enforcement
- Database connection pooling tuning
- Swagger/OpenAPI documentation

### Flutter
- Offline mode: cache feed lokal dengan `hive` atau `drift`
- Preload images untuk smooth scroll
- Haptic feedback pada reactions
- Better error messages (user-friendly, bukan error code)
- Accessibility (screen reader support)
